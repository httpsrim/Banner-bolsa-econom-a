
# Visualizador de bolsa
Este proyecto es un visualizador en pantalla completa de la bolsa.
## Despliegue

Para que funcione en un momento dado, se debe ejecutar el siguiente comando:
```bash
  python3 bolsa.py
```
o en el caso de que se use Windows:
```bash
  python3 bolsa.pyw
```
En el caso de que se quiera ejecutar una vez que se encienda el ordenador, se tiene que seguir los siguientes pasos, dependiendo del sistema operativo:
* Linux:
1. Acceder a "Aplicaciones al inicio"
2. Una vez dentro, hay que darle al botón "Añadir". Pondremos los siguientes datos:
    * **Nombre**: bolsa
    * **Comando**:/home/usuario/ruta a env/env/bin/python3 /home/rim/ruta a repositorio/src/linux/bolsa.py
    * Comentario(Es opcional): Banner de la bolsa a pantalla completa.

Después de poner estos datos, le damos a guardar. Ya está instalado.

* Windows:
1. Pulsar "WIN + R". Se abre la pequeña ventana de ejecutar.
2. Escribe esto y darle a intro:
```bash
  shell:startup
```
3. Se abre una carpeta del sistema llamada "Inicio".
4. Hacer clic derecho sobre "bolsa.pyw", copiarlo y pegar acceso directo en "Inicio"

AVISO: Esta opción tarda un rato en abrirse.
